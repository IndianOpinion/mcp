# Meta Muse

Status: **not verified** (checked 17 October 2026).

Meta's help page for Muse (https://www.meta.com/help/artificial-intelligence/1687253048996149/)
describes custom connectors that Muse builds from a service's API, but it does not mention MCP, a
server URL setting or OAuth. We found no vendor documentation for connecting Muse to a remote MCP
server, so we do not publish a recipe.

If Muse offers a remote MCP option in your account, follow the [generic MCP guide](generic-mcp.md).
If it can call an HTTP API from a description, use the [OpenAPI guide](openapi.md).

If you have a vendor link that documents this, please open an issue.
